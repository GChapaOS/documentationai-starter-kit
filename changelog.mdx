## Recent Updates

<Update label="2026-10-15" description="v2.4.0" tags={["feature", "improvement"]}>

### New Features

- Added a shipment milestone timeline so you can review status changes from pickup to delivery.
- Introduced a consolidated shipments view for teams that manage regional and cross-dock operations.
- Added support for shipping notes that stay attached to the order record across workflow stages.

### Improvements

- Improved page performance on large manifests and dense route lists.
- Refined the default documentation structure so you can add release notes faster.
- Updated field labels to be more consistent across tracking and dispatch workflows.

### Bug Fixes

- Fixed an issue where status filters reset after navigation.
- Resolved an intermittent display problem in long tracking histories.
- Corrected a date formatting mismatch in summary cards.

</Update>

<Update label="2026-09-18" description="v2.3.0" tags={["feature", "bugfix"]}>

### New Features

- Added a tracking lookup flow with clearer shipment status details.
- Added downloadable summary output for internal review and customer support.
- Included a new route notes section for dispatch teams.

### Improvements

- Simplified the steps for documenting shipment exceptions.
- Reduced the number of clicks needed to move between tracking and customer records.
- Improved empty-state messaging so users know what to do next.

### Bug Fixes

- Fixed a broken link in the documentation navigation example.
- Resolved an issue that affected saved filters in older browsers.
- Corrected spacing in the release note layout.

</Update>

<Update label="2026-08-22" description="v2.2.0" tags={["breaking", "feature", "improvement"]}>

### New Features

- Added a new workflow template for shipment intake.
- Introduced role-based task guidance for operations teams.
- Added a configurable status vocabulary so you can align labels with your process.

### Improvements

- Streamlined the documentation layout for faster onboarding.
- Improved the clarity of release summaries for non-technical readers.
- Updated example data to better reflect shipping and logistics use cases.

### Bug Fixes

- Fixed a formatting issue in long-form notes.
- Resolved an error that appeared when editing older draft entries.
- Corrected a missing description in the update list.

### Deprecated Workflows

- Deprecated the legacy intake summary flow.
- Replaced the old status naming pattern with the new configurable vocabulary.
- Marked manual handoff notes as legacy for future cleanup.

</Update>
